## Functional scope actually demonstrated

CycloneDX **JSON** import; canonical model; approved identity bridge; technical metadata; governance and geographic facts; trust events; H01 six-dimensional risk analysis, Trust Score, Evidence Coverage and Confidence; deterministic offline COMEX + DETAIL `.xlsx` export. The report reads H01 scores, it does not recalculate them. The `UNKNOWN`, `CONFLICTED`, `VERIFIED` and `NOT_APPLICABLE` statuses remain distinct.

**Not demonstrated as supported:** CycloneDX XML, SPDX JSON, SPDX XML; online enrichment without configured providers; exhaustive evidence coverage; full client-grade SBOM validation. The primary 12-component fixture currently produces a Trust Score of **100/100 with only 20% evidence coverage and LOW confidence**: this is a *limited-evidence score*, **not** a finding of high confidence or absence of risk. The primary fixture has no resolved ProjectIdentity; it does not exercise all official E/F/G archives through the full reporting pipeline. Other existing Lot E/F/G tests cover those paths.

## Golden artifacts

- `tests/baseline/manifest.json`: source SHA-256, policy SHA-256/version, archive SHA-256, Evidence/Decision/assessment IDs, runtime and limits.
- `tests/baseline/expected-assessment.json`: full JSON-compatible analysis object **including canonical inputs, enrichments, evidence/decision references, six dimensions, scores, UNKNOWN/CONFLICT, portfolio, diagnostics** plus XLSX readback semantics. Only JSON serialization of `undefined` is applied; no business fields are removed or overwritten.
- `tests/baseline/baseline-regression.test.js`: exact business golden comparison, archive/policy integrity, XLSX semantics, deterministic binary XLSX hash, twice-replayed offline output and a deliberate network-attempt failure test.
- `tests/baseline/network-block.js`: Node preload blocking `net`, `tls`, `dns`, `http`, `https`, `dgram`, and `fetch`. This verifies that **the tested Node pipeline** makes no outbound connections. It is not a machine-wide firewall; use an isolated container/network namespace for stronger OS-level assurance.

The XLSX writer produced identical bytes twice for the same fixture and policy, so its SHA-256 is pinned in the manifest **in addition to** the semantic golden. A future formatting-only change may require a reviewed update to this binary hash while preserving semantic invariants.

The supplied ZIP was tested in an environment without access to Maven Central. `node --test tests/*.test.js` produced **592 tests, 586 pass, 6 fail, 0 skipped**. The **new six baseline tests pass** with outbound network APIs blocked. The separate **Maven Identity tests (Node test runner)** pass 58/58. This is **not a fully green suite** and therefore must not be represented as a release gate passed. Run the complete suite in GitHub Actions with permitted Maven Central access and verify 0 failures before merge/tag. No business logic or tests were changed to conceal these failures.
